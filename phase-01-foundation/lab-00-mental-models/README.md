# Lab 00 — Mental Models and OSI in Practice

## Goal
Understand which layer each tool operates at so you know what you are
looking at before you start capturing any packets.

## Prerequisites
None. This is the first lab.

## Tools Used
ip, ss, curl, ping, tcpdump

## WSL2 Notes
Your primary interface is eth0. Confirm this before starting: ip addr

You can name the layer each tool operates at and explain what curl,
ping, ss, and tcpdump each see and cannot see.
